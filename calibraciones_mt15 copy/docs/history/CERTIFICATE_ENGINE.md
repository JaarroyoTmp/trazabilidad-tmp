# Certificate Engine CT-001

## Estado

**Finalizado / congelado**

## Objetivo

Generar un certificado común para toda la plataforma TMP.

## Filosofía

El certificado debe hablar como un laboratorio, no como una aplicación.

No debe mostrar:

- Core,
- Engine,
- Parser,
- JSON,
- versiones internas,
- borrador técnico,
- mensajes de desarrollo.

## Estructura

### Página 1

- Cabecera institucional.
- Dictamen final.
- Identificación administrativa.
- Datos del equipo.
- Condiciones ambientales.
- Procedimiento.
- Trazabilidad.
- Resultados principales.
- Firma / responsable.

### Página 2

- Lecturas completas.
- Cálculos.
- Incertidumbre.
- Regla de decisión.
- Trazabilidad ampliada.
- Observaciones técnicas.

## Dictamen

Solo debe existir un resultado principal:

```text
APTO / NO APTO / NO EVALUABLE
```

La incertidumbre y la regla ILAC-G8 son explicación técnica.

## QR

El QR queda preparado para futuro Pasaporte Digital del Instrumento. De momento no debe prometer una funcionalidad no implementada.
