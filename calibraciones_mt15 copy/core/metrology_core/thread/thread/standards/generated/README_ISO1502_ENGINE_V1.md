# TMP ISO1502 Engine V1

## Objetivo

Crear el primer motor ISO1502 para MT16 sin limitarlo al inventario actual.

## Alcance

- Rosca metrica ISO.
- Calibres tampon roscados para rosca interior.
- Estructura PASA / NO PASA.
- Bloqueo de decision final hasta completar y validar ISO1502.

## Archivos

- thread_iso1502_tables.js
- thread_iso1502_engine.js

## Importante

Esta V1 crea la arquitectura universal.

No debe emitir certificado final todavia.

Faltan por completar y validar:

- Tablas ISO1502 completas.
- Formulas completas de clausula 13.
- Integracion con incertidumbre.
- Regla de decision final.
