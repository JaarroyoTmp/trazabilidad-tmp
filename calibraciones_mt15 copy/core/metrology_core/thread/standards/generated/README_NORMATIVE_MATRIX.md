# TMP THREAD NORMATIVE MATRIX

## Objetivo

Centralizar que norma gobierna cada familia de rosca.

El sistema no debe asumir una norma por intuicion ni por historicos.

## Jerarquia

1. Norma aplicable
2. Tabla normativa extraida
3. Motor TMP
4. Certificado historico solo como referencia

## Ejemplo metrica ISO interna

M16x1.5-6H:

- Perfil: ISO68
- Geometria: ISO724
- Tolerancias: ISO965
- Calibres: ISO1502
- Decision: ISO14253
