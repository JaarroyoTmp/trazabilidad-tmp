# MT15 - Tampones lisos P/NP

## Estado

**Finalizado / congelado**

## Alcance

Calibración guiada de tampones lisos PASA / NO PASA.

## Criterio de diseño

- Se conserva el motor metrológico existente.
- Se moderniza la interfaz para igualarla a MT16.
- Se aplica dictamen final único.
- Se genera certificado CT-001.

## Flujo

```text
1. Equipo
2. Preguntas
3. Pauta
4. Patrones
5. Lecturas
6. Resultados
7. Guardado / certificado
```

## Regla de decisión

El usuario solo debe ver un resultado final:

```text
APTO / NO APTO / NO EVALUABLE
```

La incertidumbre, guard band e ILAC-G8 quedan documentados como evaluación metrológica.

## Estado operativo

- Conexión Supabase funcional.
- Carga de equipo funcional.
- Bloqueo por calibración vigente funcional.
- Certificado CT-001 funcional.
- Dictamen único corregido.

## No modificar salvo

- bug,
- mejora visual menor,
- ajuste normativo,
- integración con historial/certificado futuro.
