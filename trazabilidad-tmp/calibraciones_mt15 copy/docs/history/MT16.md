# MT16 - Tampones y anillos roscados P/NP

## Estado

**Finalizado / congelado**

## Alcance

Calibración guiada de tampones y anillos roscados PASA / NO PASA mediante banco Trimos.

## Criterio metrológico oficial

El patrón metrológico de MT16 es exclusivamente:

```text
Banco Trimos certificado
```

El banco aporta:

- corrección,
- incertidumbre,
- certificado,
- vigencia,
- trazabilidad.

## Rodillos / hilos

Los rodillos o hilos son accesorios de medición:

- se calculan,
- se seleccionan,
- se registran,
- no son patrones,
- no aportan incertidumbre independiente en el modelo TMP.

## Tampón patrón / patrón de rosca

No aplica al procedimiento MT16 actual de TMP.

## Normativa usada

- ISO 68-1,
- ISO 724,
- ISO 965,
- ISO 1502,
- ILAC-G8,
- ISO 14253.

## Flujo

```text
1. Equipo
2. Norma + rodillo
3. Trazabilidad
4. Preparación
5. PASA
6. NO PASA
7. Resultado
```

## Certificado

Usa CT-001 con:

- trazabilidad metrológica: banco Trimos,
- accesorios: rodillos/hilos,
- dictamen final único,
- anexo técnico.

- bug,
- adaptación normativa,
- mejora de rendimiento,
- conexión futura al pasaporte digital.
