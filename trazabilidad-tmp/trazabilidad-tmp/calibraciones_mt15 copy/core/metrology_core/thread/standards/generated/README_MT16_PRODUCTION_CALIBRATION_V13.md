# TMP MT16 V13 - Calibración técnica pura

MT16 queda sólo para calibración técnica.

Eliminado del MT16:
- Buscador general.
- Decisión de vigencia.
- Autorización de recalibración.
- Bloqueo por fechas.
- Listado general de roscas.

Responsabilidad externa:
- El futuro buscador general decide si el equipo puede calibrarse y qué MT corresponde.

MT16 hace:
- Parser rosca.
- ISO724.
- ISO965.
- ISO1502.
- Rodillo automático.
- Banco Trimos.
- Objetivos de lectura.
- Aviso de montaje.
- Lecturas PASA/NO PASA.
- Incertidumbre automática.
- Decisión con banda de guarda.
- Paquete técnico de guardado.
