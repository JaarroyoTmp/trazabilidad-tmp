# MT15 - Base normativa vigente 2026

## Alcance
Calibracion periodica de calibres tampon lisos PASA / NO PASA cilindricos completos (ISO 1938-1 Gauge type A) para caracteristicas internas, hasta 500 mm.

## Cadena normativa
1. Limites funcionales de la pieza: especificacion dimensional registrada.
2. ISO 286-1:2010: codigo/grado IT; si la tolerancia no esta expresada con codigo ISO 286, ISO 1938-1:2026 7.4 exige seleccionar el primer grado IT de Tables 7-11 cuyo intervalo sea menor o igual al intervalo real de tolerancia en el mismo rango nominal.
3. ISO 1938-1:2026: MPL del calibre (nuevo y desgaste), Clause 7, especialmente 7.2 y 7.4, Tables 6-11.
4. ISO 14253-1:2017: regla de decision considerando incertidumbre de medida.

## Revision 2015 -> 2026
ISO 1938-1:2026 (Edition 2, publicada 2026-05) sustituye ISO 1938-1:2015.
Los cambios principales declarados por ISO son:
- revision de definiciones 3.1.3, 3.1.4 y 3.2.1;
- revision de caracteristicas de diseno/metrologicas de calibres GO tipos B-K en Clause 5 y Tables 4-5;
- inclusion de gauge types H/J/K en Table B.1.

No se declaran cambios en Clause 7 ni Tables 6-11. El alcance actual MT15 usa Gauge type A; por ello se mantiene el metodo numerico MPL de Clause 7, actualizando la trazabilidad normativa a ISO 1938-1:2026.

## Regla de seguridad
Si no se pueden resolver limites MPL con datos suficientes, MT15 no emite APTO/NO APTO: queda NO_EVALUABLE y bloquea el guardado/certificacion.
